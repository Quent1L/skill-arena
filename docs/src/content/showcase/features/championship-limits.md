---
title: Championship limits
summary: A full set of fairness rules to stop a season-long championship from being gamed.
order: 2
icon: sliders
---

Championships run for weeks or months, which opens the door to gaming the standings. Skol Arena gives organizers a dedicated set of limits to close that off:

- **Max matches per player** (1–100) — a rolling cap on how many matches count toward a player's standings. Matches beyond the cap still happen and stay visible, but score zero — the oldest matches count first, so it behaves like a running best-of-N.
- **Max times with the same partner** (1–10) — caps how often the exact same teammates can pair up together.
- **Max times against the same opponent** (1–10) — caps how often the exact same two sides can face each other.
- **Allow draws** — turn draw results on or off for the whole championship.
- **Score tracking** — enable or disable numeric scores entirely, and optionally bound reported scores with a min/max range.
- **Team size bounds** — set the minimum and maximum players per team.
- **Points per victory / draw / loss** — the standings scoring system, fully configurable per championship.

Once a championship leaves draft status these settings lock — they become read-only for the rest of the season, so the rules can't shift mid-competition. Ranked seasons have their own tuning (see **Ranked mode**) and brackets don't need season-long caps at all.
